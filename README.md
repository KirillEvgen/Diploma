# SkyFitnessPro - React версия

Проект перенесен на React с использованием Vite.

## Установка

```bash
npm install
```

## Запуск проекта

```bash
npm run dev
```

Проект будет доступен по адресу: http://localhost:3000

## Сборка для продакшена

```bash
npm run build
```

## Структура проекта

```
src/
├── components/     # React компоненты
├── pages/          # Страницы
├── hooks/          # Кастомные хуки (useAuth)
├── data/           # Данные (программы тренировок)
├── css/            # Стили
└── main.jsx        # Точка входа

public/
└── images/         # Изображения
```

## Компоненты

- **Header** - Шапка сайта с логотипом и кнопкой входа
- **Hero** - Главный баннер
- **Programs** - Секция с программами тренировок
- **ProgramCard** - Карточка программы
- **Footer** - Подвал сайта
- **AuthModal** - Модальное окно авторизации
- **LoginPage** - Страница авторизации

## Хуки

- **useAuth** - Хук для управления авторизацией (login, register, logout)
