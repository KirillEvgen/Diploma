SkyFitness

Фитнес приложение на React. Можно смотреть курсы тренировок, добавлять их себе и отслеживать прогресс.

Технологии

React 18, Vite, React Router, CSS Modules. Для тестов Vitest, для линтинга ESLint.

Доступные команды

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка проекта
- `npm run lint` - проверка кода
- `npm test` - запуск тестов

Структура

Основной код в `src/`:
- `api/` - все запросы к API вынесены сюда, есть обработка ошибок
- `components/` - компоненты React
- `pages/` - страницы приложения
- `hooks/` - кастомные хуки (useAuth и т.д.)
- `css/` - глобальные стили

Функционал

- Главная страница со списком курсов
- Страница курса с деталями
- Профиль пользователя с добавленными курсами
- Страница тренировки с видео и упражнениями
- Отслеживание прогресса по упражнениям
- Авторизация через модалку или отдельную страницу
